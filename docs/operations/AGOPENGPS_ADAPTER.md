# AgOpenGPS adapter (read-only UDP/PGN observer)

**Status: IMPLEMENTED; tested over loopback with SIMULATED packets. Packet layouts are PARTLY
UNVERIFIED. Nothing here is VALIDATED, and no guidance command exists.**

Code: `src/agri_edge/adapters/agopengps_pgn.py` (pure parser),
`src/agri_edge/adapters/agopengps_udp.py` (receive-only listener + `AgOpenGpsReadOnlyAdapter`).
Tests: `tests/test_agopengps.py`; fixtures `tests/fixtures/agopengps_samples.json`
(generated by `tests/fixtures/make_agopengps_samples.py`).

## Source and what is unverified

Frame layout and PGN field lists are from AgOpenGPS-Official/Boards `PGN.md`
(<https://github.com/AgOpenGPS-Official/Boards/blob/main/PGN.md>, retrieved 2026-10-02):

```
0x80 0x81 | src | pgn | len | data (len bytes) | crc        crc = sum(bytes[2 .. n-2]) mod 256
```

Modelled PGNs: 214 GPS main antenna (51 data bytes), 253 from-autosteer, 254 steer data, 211 IMU,
239 machine data. **That document gives names, order and byte widths only.** These are assumptions,
not facts, until compared with a capture from a real AgIO: little-endian byte order; doubles for
lon/lat and floats for heading/speed/roll/altitude; signedness of angles; every unit not stated
in the document (`speed_raw` is exposed unconverted; the cross-track error scale is not
interpreted, so `GuidanceState.cross_track_error_m` is always `None`). The UDP port a given
install sends on is also unverified (9999/8888 are what AgOpenGPS forum sources describe).

**All test packets are SIMULATED**: constructed from that field list, not captured from any real
AgOpenGPS, AgIO or module.

## Safety

* **Receive-only.** The module has no `send`/`sendto`/`connect`; `tests/test_agopengps.py` asserts it from the AST.
* `engage`, `set_steer_angle`, `set_speed`, `command_steer` — and any `send*`/`set_*`/`command_*`/`write*` name — raise `GuidanceCommandRefused`. No flag turns them on.
* `GuidanceState.engaged` is always `False`. PGN 254 on the wire is a command *to* a steering module; here it is decoded as an observation (`observed().steer_data`), never replayed.
* The socket opens only with `allow_network=True` and binds loopback by default.
* Bad frames (wrong preamble, length, CRC, wrong data length for a known PGN, NaN, out-of-range
  position) are counted and dropped; they never update state or raise out of the receive loop.
* Engaging real steering stays BLOCKED-HARDWARE: it needs the SafetySupervisor and an independent hardware interlock, neither of which exists.

## Use

```python
from agri_edge.adapters import AgOpenGpsReadOnlyAdapter
a = AgOpenGpsReadOnlyAdapter(allow_network=True, port=9999, bind="127.0.0.1")
a.connect()
a.get_state()      # connected = a valid frame arrived within stale_after_s (2 s)
a.observed().gps   # GpsMainAntenna or None
a.close()
```
